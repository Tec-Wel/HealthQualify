# Owner, invention, and publication authorization — confidential evidence checklist

**Status: NOT APPROVED FOR PUBLICATION.** This repository checklist intentionally contains no patentable invention details, confidential contract terms, legal identities, employment information, attorney communications, private correspondence, or signatures. Store actual evidence in an appropriately controlled private location **outside the future public repository**. Do not commit sensitive documents or an invention disclosure here.

## 1. Identify the authorized rights holder

- [ ] Confirm the exact legal person or entity owning the original code, documentation and branding.
- [ ] Review work-for-hire terms, employment agreements, invention assignments, consulting agreements, university agreements and any external funding terms.
- [ ] Determine whether contributors, former employers, customers or collaborators have ownership or permission rights.
- [ ] Verify the authority of the person signing off for the rights holder. A GitHub username or repository admin permission alone is insufficient.
- [ ] Only then update `NOTICE` and any necessary copyright notices with the truthful holder and year(s).

## 2. Patent and trade-secret decision **before public disclosure**

- [ ] Have qualified patent counsel review any potentially patentable inventions and relevant jurisdictions.
- [ ] Check inventors, existing filings, assignment chains and prior disclosures (including demos, talks, websites and code shared with others).
- [ ] Document an authorized decision: file, retain confidentially, disclose as open source, or take no action.
- [ ] Understand that Apache-2.0 Section 3 grants recipients a license to certain contributor patent claims; publication also affects available secrecy and potentially patent rights.
- [ ] Keep invention disclosure forms, legal strategy and privileged advice outside the public repository.

## 3. Visual, dependency, and historical provenance

- [ ] Complete [independent design/IP review](INDEPENDENT_DESIGN_IP_REVIEW.md) and the draft visual/dependency inventory from PR #43 after it is independently reviewed.
- [ ] Confirm source, licenses, and redistribution rights of all bundled packages, binaries, assets, fonts, screenshots and optional model weights.
- [ ] Review all reachable Git history and other GitHub surfaces for secrets, PHI, employment-restricted IP and unauthorized materials; resolve findings before public release.
- [ ] Preserve required LICENSE/NOTICE/third-party credits, and avoid falsely suggesting partnership with referenced projects.

## 4. Contributor and brand controls

- [ ] Enforce DCO sign-off on future contributions, verify rights for historic contributions, and consider a separately reviewed contributor agreement only if the owner needs a justified additional grant.
- [ ] Verify naming/logo clearance and the rights holder before adopting an owner-specific [trademark policy](../TRADEMARK_POLICY.md).
- [ ] Confirm a working private security and community-reporting route.
