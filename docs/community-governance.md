# Contribution and community governance

HealthQualify welcomes synthetic-only, reproducible contributions. Contributors need rights to share their code under the repository Apache-2.0 terms and are requested to use Developer Certificate of Origin (DCO) signed-off commits.

- **[Contributing guide](https://github.com/Tec-Wel/HealthQualify/blob/main/CONTRIBUTING.md)**
- **[Code of Conduct](https://github.com/Tec-Wel/HealthQualify/blob/main/CODE_OF_CONDUCT.md)**
- **[Governance](https://github.com/Tec-Wel/HealthQualify/blob/main/GOVERNANCE.md)**
- **[Security disclosure](https://github.com/Tec-Wel/HealthQualify/blob/main/SECURITY.md)**
- **[Support](https://github.com/Tec-Wel/HealthQualify/blob/main/SUPPORT.md)**

Maintainers have not yet published a verified dedicated confidential community-reporting contact. This needs to be established before public launch.
